# TestQ - Love Quotes Collection 💕

A beautiful love quotes web application with real-time like counter functionality.

## Features

✨ **30 Beautiful Love Quotes** - Curated collection of romantic and inspirational quotes

❤️ **Real-time Like Counter** - Click the heart button to like your favorite quotes
- Each quote has its own like counter
- Likes are stored locally and persist across sessions
- Toggle likes on/off (heart fills when liked)
- Total likes statistics displayed

📱 **Interactive Features**
- Next Quote button with smooth transitions
- Copy quote to clipboard
- Share quotes via Web Share API (mobile)
- Responsive design for all devices

🎨 **Beautiful Design**
- Pink/Red gradient theme perfect for love quotes
- Smooth animations and transitions
- Heart beat animation on like
- Modern, clean interface

## How It Works

The like system uses browser localStorage to:
- Store individual like counts for each quote
- Remember which quotes you've liked
- Track total likes given across all quotes
- Persist data across browser sessions
